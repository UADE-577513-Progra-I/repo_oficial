# 💻 Programación I

Repositorio oficial de la asignatura **Programación I**.

En este espacio encontrarán materiales, ejemplos de código, ejercicios y recursos utilizados durante la cursada.

El objetivo de la materia es profundizar los fundamentos de programación y desarrollar la capacidad de **analizar problemas, diseñar soluciones y construir programas modulares y mantenibles utilizando Python**.

---

## 🎯 Objetivos

A lo largo de la cursada trabajaremos para:

* Consolidar los fundamentos de programación en Python.
* Diseñar soluciones utilizando un enfoque **Top-Down**.
* Descomponer problemas mediante funciones y módulos.
* Trabajar con estructuras de datos como listas y diccionarios.
* Implementar operaciones de búsqueda, ordenamiento y procesamiento de datos.
* Incorporar manejo de archivos y persistencia de información.
* Desarrollar programas robustos mediante validaciones y manejo de excepciones.
* Introducir pruebas unitarias para verificar el funcionamiento del código.
* Aplicar buenas prácticas de programación y control de versiones con Git y GitHub.

---

## 📚 Contenidos principales

Durante el curso abordaremos, entre otros, los siguientes temas:

### Fundamentos y estructuras de datos

* Variables y tipos de datos.
* Condicionales.
* Funciones.
* Listas y diccionarios.
* Listas por compmrensión.
* Búsqueda y ordenamiento.

### Programación en Python

* Modularización.
* List comprehensions.
* Funciones `lambda`.
* `map()`, `filter()` y `reduce()`.
* Expresiones regulares.
* Recursividad.
* Manejo de excepciones.

### Persistencia y calidad de código

* Archivos de texto.
* CSV.
* JSON.
* Operaciones CRUD.
* Pruebas unitarias con `pytest`.
* Buenas prácticas de programación.

## 📌 Metodología de trabajo

La materia tendrá un enfoque principalmente práctico.

A partir de diferentes problemas iremos construyendo soluciones progresivamente, buscando no solamente que el programa **funcione**, sino también que el código sea:

* claro;
* modular;
* reutilizable;
* fácil de mantener;
* y verificable mediante pruebas.

> **Programar no es solamente escribir código: es aprender a descomponer problemas y construir soluciones.**
